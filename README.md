# Simpa 雷霆音效

**This mod replaces every sound (except music) on the client with a magical meme sound! 这是一个会让你在游戏里做任何事情都会发出魔性声音的模组！**

## Function 功能

- If anything do anything, it will produce a magical sound 如果任何东西做任何事情，都会发出魔性的声音
- The sound mimics every properities for the original sounds 这个音效保留了所有属性
- Compare to data packs, this mod also redirects the sounds in other mods 相比数据包，这个模组还会对其它模组的音效生效 
- You can just pull the mod into the client side. If you pull it into the server side, it will do nothing 你只需要把它拖进客户端。如果你把它放在服务端，那么它什么都不会做

## Compatibility 兼容性

**The mod should be compatible to all mods, except to mods which Inject net.minecraft.client.sounds.SoundEngine.play at @At("HEAD") using Mixin 这个模组应该兼容任何模组，除非它们在@At("HEAD") Inject了net.minecraft.client.sounds.SoundEngine.play**
